# Plan

1. **Restate the goal** in one sentence. If it is ambiguous, ask one question, not five.
2. **Read first.** Find the files the change touches and the flow between them. Do not plan from memory.
3. **List steps**, each small enough to verify on its own. Name the file for each step.
4. **Mark what is out of scope** so it does not creep in.
5. **Define done**: the command or check that proves it works.

Keep the plan under 15 lines. Execute step by step, and verify each before moving on.
